# Implementation Roadmap

## Phase 0 — Foundation
CTO documentation, Next.js app shell, design system, Supabase schema/RLS, CI and Vercel integration.

## Phase 1 — Closed MVP
Email auth, shared listing model, browse/filter/create/manage, buyer offers, seller decisions, net-realisation calculation, responsive dashboard.

## Phase 2 — Pilot completeness
Typed category-specific forms, machinery availability calendar with DB-level overlap prevention, by-product quality model, compatible supply pools, disputes/audit trail, Kannada review and low-connectivity improvements.

## Phase 3 — Integrations
AGMARKNET/data.gov.in adapters with provenance, FPO workspace, transport quotes, notifications and authorised public-system integrations.

## Phase 4 — Commercial readiness
Pricing tests, payments only after KYC/legal/refund/dispute design, partner SLAs, security review, backup/restore drill and measured geographic expansion.

## Prioritisation
P0 = safe core workflow. P1 = pilot readiness. P2 = scale. Do not add AI, blockchain, complex analytics or native apps ahead of workflow reliability.
